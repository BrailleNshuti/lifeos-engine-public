# Decision Memo
1. Copy templates/decision-memo.md. Always include "do nothing". For each option: 12-month cost, benefit, risk, reversible or not.
2. Evidence Card: one primary source with link and date; one independent check (a test, a second source or a calculation); what would prove the recommendation wrong.
3. Commit the memo before any second opinion (pre-committed review).
4. Write a separate facts-only file for blind reviews: question, facts, constraints, no conclusion. Reviewers never see the memo.
5. Give a recommendation with a confidence level. Leave "My decision" empty: the user decides.
6. Summary numbers only: no ID numbers, bank details or exact balances.
