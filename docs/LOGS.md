# Log formats

Generated by `lifeos schema --write docs/LOGS.md`. Do not edit by hand: a test fails if it drifts from the code.

All CSV logs are UTF-8 with a header row. They only grow: nothing rewrites or deletes a row. Readers skip a damaged row instead of failing.

## logs/proofs.csv

Written by `lifeos log proof`. One row per proof (rule 1): a link, test or score.

| date | area | proof | link |
|---|---|---|---|

## logs/ledger.csv

Written by `lifeos log ledger`, `ask`, `mcp`. Minutes saved per task; feeds `week` and `experiment`.

| date | task | model | minutes_saved | note |
|---|---|---|---|---|

## logs/health.csv

Written by `lifeos log health`. Your own sleep, gym and energy numbers (class B).

| date | sleep_h | gym | energy_1_5 | note |
|---|---|---|---|---|

## logs/hours.csv

Written by `lifeos log hours`. Hours per area: german, study, lab, work.

| date | area | hours | note |
|---|---|---|---|

## logs/ratings.csv

Written by `lifeos rate`. Your 1-5 score per model and kind of task; `learn` reads it.

| date | task | model | score | kind | note |
|---|---|---|---|---|---|

## logs/predictions.csv

Written by `predict`, `resolve`, `decide`. Two row kinds: predict (value = percent) and resolve (value = 1 or 0).

| date | id | kind | value | text |
|---|---|---|---|---|

## logs/vocab.csv

Written by `vocab`. Two row kinds: add and review; boxes with gaps of 0, 1, 3, 7, 14 days.

| date | word | kind | value | text |
|---|---|---|---|---|

## logs/experiments.csv

Written by `experiment`. Two row kinds: start (value = baseline) and end (value = result).

| date | id | kind | metric | value | text |
|---|---|---|---|---|---|

## logs/runs.jsonl

One JSON object per line, written by `ask`, `delegate`, `panel`, `canary` and others. Each new record carries `prev_hash`, the SHA-256 of the line before it, so `lifeos verify` can prove nothing was edited, removed or reordered. No prompt text is stored, only sizes, hashes and flags.

## tasks/T-YYMMDD-slug.md

Front matter: `id`, `goal`, `done_when`, `route`, `level` (L0-L3), `status` (inbox, todo, doing, blocked, done), `due`. Checked by `lifeos lint`.

## decisions/D-YYMMDD-slug.md

Front matter: `id`, `title`, `date`, `revisit`, `prediction`. Written by `lifeos decide`.

## pipelines/NAME.json

`{"steps": [{"name": ..., "argv": [...], "gate": "stop" | "continue"}]}`. Run by `lifeos pipeline`.
